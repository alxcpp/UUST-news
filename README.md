# УУНиТ | Новости

Локальный новостной портал университета: читайте публикации, предлагайте новости и обсуждайте их. Предложения попадают в очередь модерации; администратор также управляет ролями модераторов.

## Возможности

- Регистрация и вход с безопасным хешированием паролей.
- Роли: пользователь, модератор и администратор. Новые аккаунты всегда создаются с ролью пользователя.
- Публикация статей и мероприятий зарегистрированными пользователями с обязательной проверкой модератором или администратором.
- Загрузка изображений к публикациям: JPG, PNG или WEBP размером до 8 МБ.
- Дата и место проведения для мероприятий; публикации появляются в ленте после одобрения.
- Предложение новости из ленты, редактирование текста перед публикацией и проверка модератором или администратором.
- Проверка десяти языковых, фактических и смысловых категорий через Gemini API. Результаты видны в очереди; исправленный черновик можно проверить, скопировать или перенести в редактор.
- Панель администратора для поиска пользователей по email и назначения ролей модератора и администратора.
- Лайки и комментарии к опубликованным новостям.
- SQLite: база и демонстрационные публикации создаются автоматически при первом запуске.

## Запуск локально

Нужен Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app app run --debug
```

Откройте http://127.0.0.1:5000. В Windows для активации окружения используйте `.venv\\Scripts\\activate`.

При первом запуске создаётся `instance/uust_news.db` и демонстрационные новости. Начальная учётная запись администратора:

- Email: `admin@uust.local`
- Пароль: `admin12345`

Для локального запуска используйте эти данные только на своём компьютере. Задайте собственный пароль до первого создания базы через переменную `ADMIN_PASSWORD`. Пароль существующего аккаунта не меняется при повторном запуске приложения.

## Роли

- **Пользователь**: читает новости, ставит лайки, комментирует и отправляет предложения на публикацию.
- **Модератор**: всё перечисленное выше, а также одобряет или отклоняет предложения.
- **Администратор**: проверяет предложения, снимает новости с публикации и назначает либо снимает роль модератора.

Права проверяются сервером. Форма регистрации не позволяет выбрать привилегированную роль.

## Настройки

- `SECRET_KEY` — секрет Flask-сессий. Для развёртывания задайте собственное случайное значение.
- `DATABASE` — необязательный путь к файлу SQLite. По умолчанию `instance/uust_news.db`.
- `ADMIN_PASSWORD` — пароль создаваемой при первом запуске учётной записи администратора.
- `GEMINI_API_KEY` — ключ Google AI Studio для Gemini API. Не добавляйте ключ в исходный код или Git.
- `GEMINI_MODEL` — модель Gemini, по умолчанию `gemini-3.8-flash`.
- `GEMINI_FALLBACK_MODELS` — список резервных моделей через запятую; при временной перегрузке основная модель переключается на резервную.
- `GEMINI_API_URL` — адрес Gemini API, обычно менять не нужно.

Для включения ИИ-проверки получите ключ в [Google AI Studio](https://aistudio.google.com/app/apikey) и задайте его в окружении перед запуском:

```bash
export GEMINI_API_KEY="your-api-key"
flask --app app run --debug
```

Gemini API может иметь бесплатную квоту; условия и лимиты зависят от региона и актуального тарифа Google. При отправке предложения заголовок, описание и текст передаются Gemini по HTTPS. Факты модель не сверяет с внешними источниками, поэтому модератор должен самостоятельно проверять источники. Без ключа приложение сохранит предложение, но не создаст AI-отчёт или исправленный черновик.

Пример для Linux/macOS:

```bash
export SECRET_KEY="replace-with-a-long-random-value"
export ADMIN_PASSWORD="replace-this-password"
export GEMINI_API_KEY="your-api-key"
flask --app app run
```

## Структура проекта

```text
app.py                 Flask-маршруты, авторизация, роли и SQLite
templates/             HTML-шаблоны страниц
static/styles.css      Адаптивные стили
instance/              Локальная база данных (создаётся автоматически)
instance/uploads/      Загруженные изображения (не попадают в Git)
```

Это учебная локальная версия. Перед публичным размещением настройте постоянный `SECRET_KEY`, смените начальный пароль, включите HTTPS и добавьте ограничения частоты запросов и резервное копирование базы.
